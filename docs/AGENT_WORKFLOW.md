# 有界工具工作流

这里的 Agent 是单个受控问答流程：解析问题、检索候选、确认实体、执行图查询、整理证据。代码在 agent/orchestrator.py；intent.py 是明确标注的本地规则解析，state.py 保存请求状态。它不是多智能体系统，也没有宣称模型原生 function calling。

默认最多 6 个阶段，不递归规划。澄清令牌绑定问题与候选，TTL 300 秒，单次消费，加锁防并发重复使用；容量有限。进程重启后旧令牌失效，用户重新提问。历史聊天不作为权限依据。

同名问题“轻旅背包价格”应返回两个带身份的候选；选择后仅使用该问题绑定的业务 ID。无实体、无结果、订单/实时库存等未实现请求明确返回无法提供，不让模型填补事实。

在线模式需要后端 key、显式授权文件、合成数据范围和调用预算；失败计入预算。DeepSeek 只解析受限结构，答案阶段只选择已有证据条目后本地格式化，不赋予任意 Cypher 执行能力。本次真实在线调用未运行。

结构化日志只存 trace_id、状态、步骤和计数，不写问题正文、原始模型输出、密码或授权头。前端展示的证据与步骤是操作摘要，不是模型隐藏思维链。
