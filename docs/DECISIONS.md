# 实施决策

公开仓库采用独立合成数据，保留课程业务链路与上游署名，课程原件和再分发许可未明确的材料不公开。发布在现有仓库的新分支完成，原主分支先备份，不覆盖私有工程或历史。

运行环境选择 Windows Python 3.12 与 CPU PyTorch；使用专属数据目录、显式解释器和空闲端口。既有 GPU、Conda、数据库环境保持原状，CPU 验证不表示 GPU 训练通过。标注、ML Backend、图与训练各自隔离。

图节点按类型与业务 ID 识别，名称可以重复或改变；输入与事务内双重校验端点，同步记录实际匹配、创建和对账结果。Tag 记录 SPU、原文 hash、跨度与来源；人工示例不能冒充模型输出。

FastAPI 只暴露业务请求，固定 Cypher 模板配合参数校验与只读业务数据库。READ_ACCESS 只是驱动路由提示，不能代替数据库权限。切换 serve 时实际尝试写入并验证被拒绝；system 库不在业务库只读范围内。

精确唯一名称或已批准别名可以直接确认，模糊候选使用 BGE/全文并要求澄清。DeepSeek 只解析受限结构、选择实际证据行；最终字段由程序格式化。没有 key 和授权时保持未运行，不调用规则假装在线模型。

前端使用原生 HTML/CSS/JavaScript 与 textContent，不依赖旧 Markdown/HTML CDN 包。通过真实 HTTP 截图和明确的模拟网络故障分别验证。

依赖漏洞会阻塞发布；升级后实际运行训练接口、保存重载、BGE 与数据库回归。随机微型模型不代表正式模型成绩。完整分发集合审计显式覆盖 CPU torch 上游版本，无跳过或忽略项。
