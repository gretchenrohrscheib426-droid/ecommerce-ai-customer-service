# 当前边界

- 3 个独立合成 SPU 只能用于功能回归；没有真实客户、线上订单、生产部署、性能对照或检索召回率结论。
- 本修订未完成正式 BERT 训练与独立测试集评估；公开 Tag 为人工示例，微型随机模型测试不代表质量。

- 单个有界工具流程；没有多智能体、任意工具执行或原生模型 function calling 的声明。
- 默认本地单进程；澄清令牌内存保存，重启失效。没有账号体系、分布式状态、生产限流或多租户隔离。
- Neo4j 业务库 serve 模式只读，system 库不受该模式保护；端口只绑定本机，禁止将示例直接公开暴露。
- 漏洞与许可检查反映检查当日的数据；不保证未知漏洞不存在。Docker、正式训练和在线模型状态独立记录。
