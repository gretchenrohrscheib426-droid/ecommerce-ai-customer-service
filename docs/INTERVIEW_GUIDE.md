# 面试解释与自检

定位：基于课程项目二次开发的本地电商图谱复现。重点说明自己能解释并经测试的修复，不把调用大模型 API 等同训练大模型，也不把单个工作流说成多智能体。

可演示输入“轻旅背包价格”，展示实体候选和选择后的真实记录。先解释为什么名称不当主键，再定位 datasync/neo4j_writer.py 与实体对齐测试。

必须能解释：Label Studio 和 ML Backend 的进程边界；训练/验证/测试的区别；word_ids 与原文跨度；特殊token -100；缺端点为什么拒绝；RRF分数不等于置信概率；参数化查询与模板门禁；模型未配置时如何如实降级。

当前用户掌握尚未验证。建议本次只练一题：Predictor 为什么不能把分词 token 直接拼成实体原文？用独立示例给出 start/end/text，并指出相关测试。先自行解释，再对照代码，不把“看懂了”当掌握。

没有真实职位、学历、毕业年、实习信息时保持待填写，不虚构求职匹配度或招聘承诺。
