# 五分钟本地演示

先按 GETTING_STARTED_WINDOWS 启动并查看 /api/status；能打开页面只证明静态资源可达，要实际提问检查证据。

1. 输入“随行水杯价格”：应显示 59，展开证据查看 SKU 字段、来源和 trace_id。说明这是虚构数据，不是实时价格。
2. 输入“轻旅背包价格”：出现青岚/白屿的两个 SPU 候选，选定一个后得到该商品价格。说明名字相同不等于节点相同。
3. 输入“青岚品牌有哪些商品”：检查品牌和 SPU 关系；观察返回的 canonical_id。
4. 输入“随行水杯标签”：说明这 4 条公开 Tag 是人工合成测试提及，真实 BERT 在私有链路，不能拿样例演示冒充预测。
5. 输入“我的订单物流”：明确不支持，没有调用订单系统。
6. 正常 stop/start 再询问水杯价格：不重新导入，验证持久化。

自动真实 HTTP 与重启检查：.venv-public/Scripts/python.exe scripts/public_verify.py --restart。浏览器 tests/e2e/chat_browser.mjs 同时包含真实 API 与明确故障注入，报告分类保存，后者不是实际网络事故。截图仅来自实际合成数据页面，不制作假的性能图或在线响应。
