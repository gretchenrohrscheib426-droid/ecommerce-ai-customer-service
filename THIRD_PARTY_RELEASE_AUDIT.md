# Third-party release audit

## Public-release decision

The supplied application archive did not contain a project-level `LICENSE`, `COPYRIGHT`, `NOTICE`, or explicit redistribution grant for the course implementation. Therefore this public portfolio does **not** redistribute the complete course source.

| Question | Finding / action |
|---|---|
| May the entire course source be republished? | Not established from the supplied materials. Withheld. |
| May attribution be removed? | No such permission was established. Attribution is retained. |
| May modified course code be republished automatically? | No. Modification alone does not establish redistribution rights. |
| Is a NOTICE file enough to create permission? | No. It records provenance only. |
| What remains outside this repository? | Course source, prompts, YAML workflow files, SQL seeds, Docker files, environment files, original archive, credentials and private configuration. |

The owner authorized publication of this restricted portfolio version. That owner authorization does not replace third-party rights-holder permission for course materials.

GitHub's general guidance on repositories without a license explains that default copyright rules apply: https://docs.github.com/articles/licensing-a-repository
